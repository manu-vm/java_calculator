# Java Calculator

> My first calculator project coded in Java.

**Try it online:** [Open the Java Calculator](https://java-calculator-vmmanu878-1875.vercel.app/)

## About this project

I built this calculator as a desktop application using Java and Swing. It was my first project where I coded a calculator myself, and it helped me learn how to create a window, place buttons, and respond to button clicks in Java.

The repository also includes a browser version so the calculator can be opened on a computer or phone without installing Java. The web version is a recreation of the calculator's basic operations; it does not run the original Swing window in the browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number input
- Clear button
- Keyboard support in the web version
- Responsive web app for desktop and mobile

## Run the original Java desktop program

Install a Java Development Kit, then open a terminal in this folder and run:

```bash
javac Calculator.java
java Calculator
```
